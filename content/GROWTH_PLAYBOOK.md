# 100일 1000명 구독자 — 콘텐츠 파괴적 성장 전략

## 핵심 원칙

1. **교육보다 성장.** 맞는 내용이 중요한 게 아니다. 저장·공유·팔로우를 유도하는 게 더 중요하다.
2. **알고리즘은 참여율(댓글·저장·공유)에 반응한다.** 조회수보다 참여율.
3. **첫 3초가 모든 걸 결정한다.** 커버 카드가 약하면 나머지 9장은 아무도 안 본다.
4. **모든 카드는 하나의 액션을 요구해야 한다.** "저장하세요", "팔로우하세요", "댓글 남기세요".

## 허용되는 파괴 (기존 STYLE.md 우선순위보다 상위)

### 톤 & 말투
- 반말, 말줄임 허용: "왜일까? → 답은 여기에 👇"
- 질문형 커버: "너 이거 모르면 AI 개발자 아니야"
- 호기심 유발: "GPT가 절대 답을 안 하는 질문 3가지"
- 과장 허용 (단, 내용은 정확히): "미쳤습니다", "혁명", "충격실화"

### 포맷 실험
- **5~7장 숏 캐러셀**: 완독률 2배, 저장률 1.5배 (인스타 데이터 기준)
- **퀴즈 카드**: "정답은 스와이프!" 형식 (댓글 유도)
- **비유 폭격**: 처음 3장을 하나의 일상 비유로 통일 (공감 → 저장)
- **시리즈 연계**: 각 카드 하단에 "🔗 2편 보러가기" 링크 멘션
- **웹툰형**: 4컷 만화 형식으로 개념 설명 (공유율 최고)

### CTA 전략
- **모든 카드 하단**에 `💾 저장하세요` 텍스트 삽입
- 10번 카드는 "이 시리즈 놓치지 않으려면 팔로우 ➕"로 고정
- 캡션에 주기적으로 "댓글로 궁금한 주제 알려주세요"

### 해시태그 전략
- 소형 태그 5개는 **실시간 트렌딩 태그**로 교체 (AI 뉴스 이슈)
- 매일 해시태그 풀을 30%씩 로테이션 (팔로우하지 않은 계정에 노출)
- `#인공지능 #AI` 외에 `#ai뉴스 #AI트렌드 #오늘의AI` 트렌드 태그 추가

## 콘텐츠 믹스 (7일 기준)

| 일 | 포맷 | 예시 |
|----|------|------|
| 월 | 이론 폭격 | 클래식 10장, but 커버 파괴적 |
| 화 | AI 뉴스 속보 | 오늘 나온 논문/발표 24시간 내 정리 |
| 수 | 시리즈 n/n | 전편 저장 유도 + 새 내용 |
| 목 | 퀴즈/밈 | 참여형, 공유형 |
| 금 | 비교/논쟁 | "A vs B, 당신의 선택은?" |
| 토 | 깊은 비유 | 일상 경험으로 AI 설명 (저장률↑) |
| 일 | 요약/체크리스트 | "이 5가지만 알면 됨" 리스트형 |
